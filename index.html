Guia de Bolso Git

Comandos Essenciais

git init

O comando git init é utilizado para inicializar um novo repositório Git em um diretório.

git add .

O comando git add . é utilizado para adicionar todos os arquivos modificados ao stage.

git commit -m "mensagem"

O comando git commit -m "mensagem" é usado para salvar alterações no repositório local do Git. Permitindo registrar as mudanças e o estado atual do projeto.

git push -u origin main

O comando git push -u origin main é utilizado para enviar as alterações para o repositório remoto.

git fetch

O comando git fetch é utilizado para obter as alterações mais recentes de um repositório remoto, mas sem integrá-las ao seu branch local.

git pull

O comando git pull é utilizado para buscar e integrar as alterações mais recentes de um repositório remoto ao seu branch local.

git clone

O comando git clone é utilizado para criar uma cópia, clonar o repositório ou projeto do GitHub.

git remote add origin

O comando git remote add origin é utilizado para adicionar um repositório remoto chamado "origin".

Dica: Utilize este guia como referência para os comandos mais utilizados do Git.
